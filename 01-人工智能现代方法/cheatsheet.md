# 速查表

## 核心公式
| 场景 | 内容 |
|---|---|
| A* 评价 | f(n)=g(n)+h(n) |
| Minimax | 自己 max，对手 min |
| 贝叶斯 | P(a|b)=P(b|a)P(a)/P(b) |
| 贝叶斯网 | P(X)=ΠP(Xi|Parents(Xi)) |
| 滤波预测 | Σ P(X'|x)P(x|e) |
| 期望效用 | EU(a)=ΣP(s|e)U(s) |
| 信息增益 | H(parent)-Σ(n_i/n)H(child_i) |
| 贝尔曼 | v(s)=Σπ(a|s)Σp[r+γv(s')] |
| 反向传播 | ∂L/∂w=∂L/∂y·∂y/∂w |
| 注意力 | softmax(QKᵀ/√d_k)V |
