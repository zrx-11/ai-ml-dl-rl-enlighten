# 深度学习入门：基于 Python 的理论与实现 点化学习系统

## 这本书在讲什么
这本书只做一件事：不用任何框架，把神经网络从乘法加法开始搭出来，最后在 MNIST 上跑出 98% 以上的准确率。作者刻意不介绍研究前沿和框架用法，所有算法都用 NumPy 手写，因此每一步都能被验算。读它的价值不在结论，而在“每个环节我都亲手算过一遍”这条路径。
