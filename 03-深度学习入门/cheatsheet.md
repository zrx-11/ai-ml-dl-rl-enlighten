# 速查表

## 公式
| 场景 | 内容 |
|---|---|
| 矩阵乘法形状 | (m,n) @ (n,p) → (m,p) |
| sigmoid 与导数 | σ(x)=1/(1+e^{-x})，σ'=σ(1-σ) |
| softmax | y_k=e^{a_k}/Σe^{a_i} |
| 交叉熵 | E=-Σ t_k log y_k |
| 均方误差 | E=½Σ(y_k-t_k)² |
| 中心差分 | f'(x)≈[f(x+h)-f(x-h)]/(2h)，h≈1e-4 |
| 梯度下降 | W ← W - η ∂E/∂W |
| 卷积输出尺寸 | (H-KH+2P)/S+1 |

## 训练流程
1. 取 mini-batch → 2. 前向 → 3. 算损失 → 4. 反向算梯度 → 5. 优化器更新 → 6. 重复至一个 epoch 结束 → 7. 在验证集评估，挑超参数 → 8. 最后用测试集报一次成绩。

## 排错顺序
损失不降 → 学习率、初始化、激活函数、梯度是否消失；损失降但泛化差 → 正则、数据增强、早停；数值溢出 → softmax 先减最大值、log 加 eps。
