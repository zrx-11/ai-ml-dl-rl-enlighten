# 模式与框架库

## 框架：从“算得出”到“学得会”的四层结构
本书所有算法都落在同一个骨架上：**表示（用什么函数）→ 损失（错得多离谱）→ 梯度（往哪改）→ 更新（改多少）**。遇到任何新模型，先把它按这四层拆开，缺哪一层就是读不懂的地方。

## 决策规则
- 要判断某个操作能不能训练 → 看它有没有可写的导数；没有就换光滑替代（阶跃→sigmoid，硬阈值→softmax+交叉熵）。
- 要做分类 → 输出层 softmax，损失交叉熵；要做回归 → 恒等输出，损失均方误差。
- 网络训不动 → 依次查：梯度是否消失（换 ReLU/加归一化）、初始化是否合理、学习率是否过大。
- 训练集好测试集差 → 先加正则（权值衰减、Dropout、数据增强），再考虑加数据。

## 反模式
- **用数值微分训练**：慢两三个数量级，只配当验算工具。
- **权重全零初始化**：对称性不破，整层等价于一个神经元。
- **拿测试集调超参数**：评估结果虚高，等于自欺。
- **只堆层数不看梯度**：sigmoid 叠加会梯度消失，加深反而更差。
