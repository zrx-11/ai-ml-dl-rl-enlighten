# 速查表

## 公式
| 场景 | 内容 |
|---|---|
| 最小二乘 | w=(XᵀX)^{-1}Xᵀy |
| 对数几率回归损失 | L=Σ[-y log ŷ-(1-y)log(1-ŷ)] |
| 信息熵 | Ent=-Σp_k log2 p_k |
| 信息增益 | Gain=Ent(D)-Σ(|D_v|/|D|)Ent(D_v) |
| F1 | 2PR/(P+R) |
| SVM 原问题 | min ½||w||² s.t. y_i(wᵀx_i+b)≥1 |
| AdaBoost 学习器权重 | α=½ln((1-ε)/ε) |
| PCA | 中心化 → 协方差 → 特征分解 → 取大特征值方向 |
| Q-learning | Q(s,a)←Q(s,a)+α[r+γmax Q(s',a')-Q(s,a)] |

## 算法选择速查
| 任务 | 首选 | 备选 |
|---|---|---|
| 中小规模分类 | 随机森林 / XGBoost | 逻辑回归、SVM |
| 高维稀疏文本 | 朴素贝叶斯、线性 SVM | L1 逻辑回归 |
| 需要可解释 | 决策树、规则学习 | 线性模型 |
| 无标签分组 | k-means、DBSCAN | 层次聚类 |
| 降维可视化 | PCA、t-SNE | Isomap、LLE |
| 序列决策 | Q-learning、策略梯度 | 见强化学习专书 |

## 排错顺序
训练误差高 → 模型容量不足（加特征、换模型）；训练低测试高 → 过拟合（正则、集成、加数据）；两者都高 → 数据问题（标签噪声、特征缺失）。
