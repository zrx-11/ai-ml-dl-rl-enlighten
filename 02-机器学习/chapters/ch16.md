# 第 16 章：强化学习

- **难度**：★★☆ | **预估学时**：3 小时 | **前置**：第 1、3、7 章；对接 Sutton 专书

## 学习目标
学完本章，你能：说清强化学习与监督学习的任务差异；写出 K 臂赌博机的 ε-贪心策略并解释探索与利用的权衡；写出 MDP 的四元组与贝尔曼方程；说明 Q-learning 与 Sarsa 的差别。

## 一句话核心
强化学习没有标准答案，只有延迟的奖励；它必须在“试错”中同时学会“什么状态好”和“什么动作对”。

## 零基础讲解

### 概念 1：任务设定（难度：基础）
智能体在环境里执行动作，环境给出新状态和奖励。目标是最大化**长期累积奖励**，不是眼前这一步的奖励。

**与监督学习的三个不同**：没有即时标签（奖励可能延迟几十步）、数据由自己的策略产生（非独立同分布）、探索会影响后续见到的数据。

### 概念 2：K 臂赌博机（难度：进阶）
K 个摇臂，每个有未知的期望收益。**ε-贪心**：以 ε 概率随机探索，以 1-ε 概率选当前估计最好的。**乐观初始值**：把所有估计初值设高，逼算法先把每个臂都试一遍。**UCB**：按“均值 + 不确定性奖励”选，`a = argmax Q(a) + c√(ln t / N(a))`，被试得少的臂获得额外加分。

**实例**：两个臂，真实收益 0.8 和 0.5。ε=0.1 时，90% 的步都选当前最优，10% 用于探索。前期探索多、后期收敛到 0.8 那个臂，但永远保留 10% 的“学费”。

### 概念 3：MDP 与贝尔曼方程（难度：高难）
MDP 四元组 `(S, A, P, R)`：状态、动作、转移概率、奖励。策略 π 给出每个状态下选动作的概率。

**状态价值**：`v_π(s) = Σ_a π(a|s) Σ_{s'} P(s'|s,a)[R + γ v_π(s')]`。
**动作价值**：`q_π(s,a) = Σ_{s'} P(s'|s,a)[R + γ Σ_{a'} π(a'|s') q_π(s',a')]`。

**γ 的作用**：折扣因子，越接近 1 越看重长远，越接近 0 越短视。它同时保证无穷和收敛。

### 概念 4：TD 与 Q-learning（难度：高难）
**TD(0) 更新**：`V(s) ← V(s) + α[r + γV(s') - V(s)]`。方括号里是“实际看到的 + 对未来的估计”减去“原来的估计”，叫 TD 误差。它不需要等一幕结束，边走边学。

**Q-learning**（离轨策略）：`Q(s,a) ← Q(s,a) + α[r + γ max_{a'} Q(s',a') - Q(s,a)]`。用下一状态的最大动作价值，不管实际下一步选了什么。

**Sarsa**（同轨策略）：把 `max Q(s',a')` 换成实际选的 `Q(s',a')`。它学的是“当前这个策略的价值”，Q-learning 学的是“最优策略的价值”。

## 常见误解
- 别以为奖励越大越好就一定对——实际上延迟奖励可能要求牺牲眼前收益。
- 别以为 Q-learning 一定比 Sarsa 好——实际上在危险环境下 Sarsa 更保守安全，因为它评估的是实际执行的策略。
- 别以为 γ 只是数学技巧——它决定了智能体的“视野长度”，直接影响行为。

## 复习锚点
- RL 的核心难点：奖励延迟、数据自产、必须探索。
- 贝尔曼方程：当前价值 = 即时奖励 + 折扣后的下一状态价值。
- Q-learning 离轨用 max，Sarsa 同轨用实际动作。
