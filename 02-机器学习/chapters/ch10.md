# 第 10 章：降维与度量学习

- **难度**：★★★ | **预估学时**：4 小时 | **前置**：第 9 章、线性代数（特征值分解）

## 学习目标
学完本章，你能：说清 kNN 的“懒惰学习”特点与维度灾难的关系；推出 PCA 的优化目标并解释为什么取协方差矩阵最大的特征向量；区分 PCA 与 MDS 的出发点；说明流形学习的核心假设。

## 一句话核心
降维的实质是找一个低维坐标系，让数据在丢掉一些方向后仍然尽量保持原本的结构。

## 零基础讲解

### 概念 1：kNN 与维度灾难（难度：基础）
kNN 不训练，来一个样本就找最近的 k 个邻居投票。它属于**懒惰学习**（lazy learning）。

**维度灾难**：维度升高时，空间体积指数增长，样本变得极稀疏，任何两点之间的距离都差不多，“最近邻”失去区分度。这是 kNN 在高维上失效的根本原因，也是降维的动机之一。

### 概念 2：PCA（难度：高难）
目标：把数据投影到低维，使投影后样本尽量分散（方差最大）。

**推导三步**：
1. 中心化：`X ← X - mean`，让每个特征均值为 0。
2. 协方差矩阵 `C = XᵀX/(m-1)`，它描述各特征之间的线性相关。
3. 对 C 做特征值分解，取最大的 d' 个特征值对应的特征向量组成投影矩阵 W，`Z = XW`。

**为什么取最大特征值**：投影后的方差等于 `wᵀCw`，在 ||w||=1 约束下最大化它，拉格朗日法直接给出 `Cw=λw`——所以最优方向就是 C 的特征向量，方差就是特征值。前 d' 个特征值之和占总和的比例就是**累计贡献率**。

**实例**：二维数据完全落在直线 y=x 上，协方差矩阵的特征值是 2 和 0，取第一个特征向量 (1,1)/√2，一维投影不损失任何信息，因为第二维方差为 0。

### 概念 3：MDS 与流形学习（难度：高难）
**MDS** 不关心方差，要求降维后样本间的**距离**尽量保持。它和 PCA 在欧氏距离下等价，但 MDS 可以接任意距离（比如测地距离）。

**流形学习**假设高维数据其实躺在一个低维曲面上（比如卷起来的纸）。Isomap 用近邻图上的最短路径近似测地距离再做 MDS；LLE 用局部线性重构关系来保持邻域结构。

**为什么需要流形**：瑞士卷这类数据，欧氏距离会把“隔着纸”的两点当成近邻，PCA 完全失效；沿曲面走的距离才是真距离。

看图说明：核心在第 5 步——选择几个特征向量就是选择保留多少信息。特征值小的方向被丢掉，那里通常对应噪声。

## 常见误解
- 别以为降维一定损失信息——实际上如果数据真在低维子空间上，丢掉的特征值本来就接近 0。
- 别以为 PCA 能解决所有降维问题——实际上它只捕捉线性结构，非线性流形要换方法。
- 别以为 kNN 不需要训练所以简单——实际上预测时要扫全库算距离，大数据上非常慢，通常配 KD 树或近似最近邻。

## 复习锚点
- 降维 = 换坐标系 + 丢方向。
- PCA：中心化 → 协方差 → 特征分解 → 取大特征值方向。
- 累计贡献率 = 前 d 个特征值之和 / 全部特征值之和。
- 流形学习要保的是“沿曲面的距离”，不是直线距离。
