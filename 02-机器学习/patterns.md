# 模式与框架库

## 框架：偏差—方差—容量三角
任何模型选择问题都能拆成三问：模型容量够不够（欠拟合？）、方差大不大（过拟合？）、数据量与容量匹配不匹配。周志华全书反复用这个三角解释为什么某个技巧有效。

## 决策规则
- 数据少、特征多 → 先降维或加 L1，再用简单模型。
- 训练好测试差 → 先查数据划分是否泄露，再加正则/集成。
- 类别不平衡 → 先看业务代价，再决定调阈值、采样还是换评价指标。
- 线性不可分 → 先试核 SVM 或树集成，不要直接上深度网络。
- 没有标签 → 先聚类看结构，再考虑半监督。

## 反模式
- **用测试集调参**：评估结果虚高，是实验设计层面的错误。
- **不做显著性检验就宣称更优**：单次划分的波动常大于模型差异。
- **只看准确率**：不平衡数据上准确率会被多数类主导。
- **盲目堆特征**：冗余特征增加方差，噪声特征直接伤害泛化。
