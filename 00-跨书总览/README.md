# 跨书总览：AI / ML / DL / RL 的一条学习路线

五本书不是并列的五本参考书，而是**一张地图 + 四块深挖**。《人工智能：现代方法》给出坐标，其余四本各自负责一块：传统机器学习、深度学习的最小实现、深度学习的工程实现、强化学习的完整理论。

## 推荐学习顺序

| 顺序 | 书 | 为什么在这个位置 | 能力里程碑 |
|---|---|---|---|
| 1 | 《人工智能：现代方法》第 1、2、3 章 | 先建立“智能体 = 感知—决策—行动”的框架和状态空间搜索的语言，后面所有方法都能挂到这个框架上 | 能用 PEAS 描述一个 AI 产品；能跑通一次 A* 并说明启发函数为什么必须可采纳 |
| 2 | 《机器学习》第 1—4 章 | 这是全五本里对“评估”讲得最细的一段。没有评估就没有后面任何调参，跳过它会一直在盲调 | 能手算信息增益；能说清训练误差、验证误差、泛化误差的区别；能解释过拟合的四种对策 |
| 3 | 《深度学习入门》第 1—5 章 | 用 NumPy 手写感知机到反向传播。它的价值是“没有框架遮住中间量”，适合把第 1 页推导页的每个数字对上代码 | 能手推两层网络的反向传播；能手写一个不依赖框架的两层网络并跑通 |
| 4 | 《机器学习》第 5—8 章 | 回到传统方法：神经网络基础、SVM、贝叶斯、集成。SVM 的对偶与核技巧是理解“为什么有些模型在小数据上仍然强”的关键 | 能用具体数字演示同一个决策边界对应无穷组 (w,b)；能说清核技巧避免了什么计算 |
| 5 | 《动手学深度学习》第 2—5 章 | 换成框架实现，学数据管道、自动求导、训练循环、CNN。此时你已经知道底层在算什么，不会被 API 迷惑 | 能独立写一个完整的训练循环并读懂每个超参的作用；能用 GPU 跑通一个 CNN |
| 6 | 《人工智能：现代方法》第 12—17 章 | 概率与决策。这里是从“符号 AI”转向“统计 AI”的关口，也是《机器学习》第 7、14 章的抽象版 | 能手算一次贝叶斯后验与一次滤波更新；能解释 POMDP 为什么在信念空间上决策 |
| 7 | 《强化学习》第 1—8 章 | 序贯决策的主干：MDP、贝尔曼、DP、MC、TD、n 步、Dyna。这本是唯一把“延迟奖励”讲到底的书 | 能手解两状态价值方程；能写出 Sarsa 与 Q-learning 并说出行为差异；能画出 Dyna 结构 |
| 8 | 《强化学习》第 9—13 章 | 函数逼近与策略梯度。从这一层开始，稳定性问题成为主线，也是深度 RL 的理论入口 | 能写出半梯度 TD 并说明“半”在哪；能解释致命三要素；能手推 REINFORCE 并解释基线为什么不引入偏差 |
| 9 | 《机器学习》第 9—15 章 | 聚类、降维、稀疏、计算学习理论、半监督、图模型、规则学习。这一段是知识面补齐，可按兴趣选读 | 能说清 PCA 与 LDA 的目标差异；能解释 EM 的单调性 |
| 10 | 《动手学深度学习》第 6—10 章 + AIMA 第 23—25 章 | 序列、优化、性能、视觉、NLP。深度学习的两大应用面在这里合流 | 能说明自注意力为什么把路径长度降到常数；能读懂一个 Transformer 编码器 |
| 11 | 《人工智能：现代方法》第 18、26—28 章 | 收尾：多智能体、机器人、伦理、未来。把技术放回物理与社会语境 | 能说出对齐问题的技术版本（奖励黑客）；能判断一个 AI 宣称是否可信 |

## 各书定位（一句话）

- **《人工智能：现代方法（第 4 版）》**：覆盖全领域的地图，28 章里有一半（搜索、逻辑、规划、机器人）是其余四本完全不涉及的符号方法；不适合当第一本算法手册用，适合当索引。
- **《机器学习（周志华）》**：传统方法的字典，评估与理论部分最扎实；不适合入门深度学习，公式密度高、几乎没有代码。
- **《深度学习入门（斋藤康毅）》**：从零实现的教科书，8 章全部可以手写；不适合学工程实践，规模小、没有 GPU 与数据管道。
- **《动手学深度学习》**：工程实现手册，代码与讲解一一对应；不适合当理论书，很多推导被略过。
- **《强化学习（第 2 版）》**：把延迟奖励下的决策讲到底的唯一一本；不适合当第一本 ML 书，第 9 章之后需要函数逼近与概率的基础。

## 学习节奏建议

- **每周 8—10 小时**：3 小时读章节，3 小时做手算与代码，2 小时做自测与抽认卡，1 小时交叉复习。
- **不要按书的顺序线性推进**。第 1—5 步走完大约 10 周；第 6—8 步是第二个大块，约 8 周；第 9—11 步可以按兴趣挑，4—6 周。
- **每完成一本书，回到跨书概念映射表**看同一个概念在其他书里怎么讲。这一步的收益大于再读一章。
- **卡住时的顺序**：概念不懂 → 查术语表；推导跟不上 → 去看对应推导页（06-从零推导/）；代码跑不通 → 去《动手学深度学习》对应章。
