# 速查表

## 公式
| 场景 | 内容 |
|---|---|
| softmax | ŷ_j=exp(o_j)/Σexp(o_k) |
| 交叉熵梯度 | ∂ℓ/∂o_j=ŷ_j-y_j |
| 卷积输出尺寸 | (H-K+2P)/S+1 |
| RNN 隐状态 | h_t=φ(W_hh h_{t-1}+W_xh x_t+b_h) |
| LSTM 细胞状态 | c_t=f_t⊙c_{t-1}+i_t⊙c̃_t |
| 动量 | v_t=βv_{t-1}+g_t |
| Adam 修正 | m̂=m/(1-β₁^t)，v̂=v/(1-β₂^t) |
| 自注意力 | softmax(QKᵀ/√d_k)V |
| IoU | 交集面积/并集面积 |

## 训练配置速查
| 场景 | 常用设置 |
|---|---|
| 图像分类 | batch 64-256，lr 1e-3，Adam，余弦退火 |
| 微调 | 骨干 lr 1e-5，新头 1e-3 |
| 序列任务 | 梯度裁剪 1.0，预热 10% 步数 |
| 显存紧张 | 混合精度 + 梯度累积 |

## 排错顺序
形状 → 损失是否下降 → 是否 NaN → 显存 → 可复现性。
