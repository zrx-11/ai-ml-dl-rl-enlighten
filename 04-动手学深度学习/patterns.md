# 模式与框架库

## 框架：一个模型的三层坐标
读任何一个模型，先定位三件事：**输入什么形状**、**参数在哪一层**、**损失怎么定义**。这三件定了，剩下的都是实现细节。

## 决策规则
- 任务是图像 → 先上卷积骨干 + 迁移学习，不要从零训。
- 任务是序列 → 短序列用 RNN/GRU，长序列或需要并行用 Transformer。
- 训练不收敛 → 先降学习率到 1e-4 试，再看梯度范数。
- 显存不够 → 减 batch 优先，其次梯度累积，最后混合精度。
- 数据少 → 增广 + 微调 + 早停，三件套一起上。

## 反模式
- **不打印 shape 就写模型**：形状错误是最高频的 bug 源。
- **照抄超参数**：别人的 1e-3 到你的任务上未必成立。
- **只看训练损失**：训练损失降、验证损失升就是过拟合。
