# 第 5 章：蒙特卡洛方法

- **难度**：★★★ | **预估学时**：4 小时 | **前置**：第 4 章、期望与方差

## 学习目标
学完本章，你能：区分首次访问与每次访问 MC；说出 MC 与 DP 的根本差别；写出同轨策略 MC 控制的流程；解释重要性采样为什么需要、普通与加权两种估计的取舍。

## 一句话核心
MC 不靠模型，靠“把一整幕跑完，用真实回报当目标”；它的估计无偏，但方差大。

## 零基础讲解

### 概念 1：用回报代替期望（难度：进阶）
`V(s) ← 平均(该状态之后实际得到的 G_t)`。不需要转移概率，只要有完整的一幕。

**与 DP 的对比**：DP 用“下一状态价值的期望”更新（自举、有偏、低方差）；MC 用“实际回报”更新（不自举、无偏、高方差）。这是强化学习里最核心的一组权衡。

### 概念 2：首次访问与每次访问（难度：进阶）
- **首次访问 MC**：每幕里只在该状态第一次出现时更新一次。
- **每次访问 MC**：每次出现都更新。

两者都收敛到 v_π。首次访问的估计更“独立”，每次访问样本利用率更高但样本相关。

### 概念 3：MC 控制（难度：高难）
估值对象是 q(s,a)，因为没模型时只知道 v 无法选动作。流程：按当前策略跑完一幕 → 对每个出现的 (s,a) 用回报更新 Q → 用 Q 做 ε-贪婪改进 → 重复。

**探索问题**：如果策略是纯贪婪，某些 (s,a) 永远不会被访问，Q 永远得不到更新。所以必须 ε-软策略，或者用“探索起点”（每一幕从随机状态动作开始）。

### 概念 4：离轨重要性采样（难度：高难）
离轨时数据由行为策略 b 产生，要评估目标策略 π。用重要性采样比率 `ρ = Π π(a_t|s_t)/b(a_t|s_t)` 给回报加权，修正分布差异。

- **普通重要性采样**：`V = (Σρ·G)/n`，无偏但方差可能极大（比率连乘会爆炸）。
- **加权重要性采样**：`V = Σ(ρ·G)/Σρ`，有偏但方差小得多，实践中更常用。

**为什么会爆炸**：序列越长，连乘的比率越多；若 π 与 b 差异大，单个 ρ 就能到 10^3 量级，一个样本把平均值拉飞。

## 常见误解
- 别以为 MC 无偏就一定更好——实际上方差大意味着需要更多样本，实际收敛可能更慢。
- 别以为重要性采样只是加权——实际上普通 IS 的方差可能无界，工程上几乎都用加权版本。
- 别以为 MC 只能用于分幕任务——实际上持续式任务也能用，但要截断或用平均收益形式。

## 复习锚点
- MC：跑完整幕、用真实回报、无偏高方差、不需要模型。
- 首次访问 vs 每次访问：更新频率不同，都收敛。
- 控制要估 q 不要估 v；必须保持探索。
- 加权重要性采样：有偏但方差小，实际首选。
