# 第 3 章：有限马尔可夫决策过程

- **难度**：★★★ | **预估学时**：5 小时 | **前置**：第 2 章、概率与期望

## 学习目标
学完本章，你能：写出回报的定义并说明折扣因子的两个作用；推导贝尔曼期望方程；区分 v(s) 与 q(s,a) 并写出两者的关系式；推导贝尔曼最优方程并说明 max 的位置。

## 一句话核心
MDP 把“决策问题”形式化成四元组，贝尔曼方程则把“长期价值”递归成“即时奖励 + 下一状态价值”。

## 零基础讲解

### 概念 1：MDP 与回报（难度：基础）
四元组 `(S, A, P, R)`，其中 `P(s',r|s,a)` 是转移概率。回报 `G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + ...`。

**γ 的两个作用**：一是数学上保证无穷和收敛（γ<1 时上界是 R_max/(1-γ)）；二是语义上控制“短视程度”，γ 越接近 1 越看重长远。

**episodic 与 continuing**：有终止状态的任务叫分幕式，回报是有限和；没有终止的叫持续式，必须靠折扣才收敛。

### 概念 2：贝尔曼期望方程（难度：高难）
`v_π(s) = Σ_a π(a|s) Σ_{s',r} p(s',r|s,a)[r + γ v_π(s')]`。

**推导过程**：把 G_t 拆成 `R_{t+1} + γG_{t+1}`，对 G_{t+1} 取期望就得到 `v_π(s')`，再对动作和转移概率求期望。**这一步是全章的核心：它把“无穷长的和”变成了“一步 + 下一状态的价值”。**

`q_π(s,a) = Σ_{s',r} p(s',r|s,a)[r + γ Σ_{a'} π(a'|s') q_π(s',a')]`。

**两者的关系**：`v_π(s) = Σ_a π(a|s) q_π(s,a)`；`q_π(s,a) = Σ_{s',r} p[r + γ v_π(s')]`。

### 概念 3：贝尔曼最优方程（难度：高难）
`v_*(s) = max_a Σ_{s',r} p(s',r|s,a)[r + γ v_*(s')]`，
`q_*(s,a) = Σ_{s',r} p(s',r|s,a)[r + γ max_{a'} q_*(s',a')]`。

**max 的位置很关键**：它必须在动作上取，而不是在状态上。因为策略是对动作的选择。贝尔曼最优方程是非线性的（因为有 max），这导致它一般没有闭式解，只能迭代求解。

**为什么最优策略一定存在且是确定性的**：对有限 MDP，存在一个确定性策略在每个状态都取使 q_*(s,a) 最大的动作，且它同时最优于所有状态。

### 概念 4：一个手算实例（难度：进阶）
两状态 A、B，A 执行动作后必到 B 得奖励 0；B 执行动作后必回 A 得奖励 1。γ=0.9。
设 v(A)=x，v(B)=y。贝尔曼：x = 0 + 0.9y，y = 1 + 0.9x。
解得：x = 0.9(1+0.9x) = 0.9+0.81x → 0.19x=0.9 → x=4.7368，y=5.2632。
验算：从 A 出发每两步拿 1，折扣后总回报 = 0.9 + 0.81×... 收敛到 4.7368，对得上。

## 常见误解
- 别以为 γ=1 一定更好——实际上持续式任务里 γ=1 会让回报发散，且让智能体完全不为未来打折、难以收敛。
- 别以为最优价值函数可以直接算出来——实际上有 max 就没有闭式解，必须迭代。
- 别以为 v 和 q 只是记号不同——实际上 q 多了一个动作维度，是控制问题里真正要用的量。

## 自测题（答案）
1. γ 的作用不包括？（答案：C；解析：它保证收敛并控制视野，不改变奖励尺度。）
   - A. 保证无穷和收敛　B. 控制短视程度　C. 放大即时奖励　D. 使持续式任务有定义
2. 贝尔曼最优方程中 max 取在哪一维？（答案：A；解析：在动作上取，因为策略选的是动作。）
   - A. 动作　B. 状态　C. 时间　D. 奖励
3. v_π 与 q_π 的关系是？（答案：B；解析：v 是 q 在策略分布下的期望。）
   - A. q 是 v 的期望　B. v 是 q 按策略加权平均　C. 两者相等　D. 无法关联

## 复习锚点
- G_t = R_{t+1} + γG_{t+1}，贝尔曼方程靠这个递推。
- γ 保证收敛 + 控制视野。
- 最优方程在动作上取 max，非线性，需迭代。
- v_π(s)=Σπ(a|s)q_π(s,a)。
