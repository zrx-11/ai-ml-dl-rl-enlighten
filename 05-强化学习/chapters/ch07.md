# 第 7 章：n 步自举法

- **难度**：★★★ | **预估学时**：3 小时 | **前置**：第 5、6 章

## 学习目标
学完本章，你能：写出 n 步 TD 的回报形式；说明 n 从 1 增大到无穷时如何从 TD 连续过渡到 MC；解释 n 步方法为什么在偏差与方差之间提供连续的旋钮；说清树回溯与 n 步的关系。

## 一句话核心
n 步就是把“等几步再自举”这件事变成一个可调参数：n=1 是 TD，n=∞ 是 MC。

## 零基础讲解

### 概念 1：n 步回报（难度：进阶）
`G_{t:t+n} = R_{t+1} + γR_{t+2} + ... + γ^{n-1}R_{t+n} + γ^n V(S_{t+n})`。

前 n 个奖励是真实的，最后一个用估计收尾。n=1 时就是 TD(0)：`R_{t+1}+γV(S_{t+1})`；n 趋于无穷（或到幕结束）时就是 MC 的完整回报。

### 概念 2：偏差与方差的连续调节（难度：进阶）
n 小 → 更多依赖估计（偏差大、方差小）；n 大 → 更多依赖真实奖励（偏差小、方差大）。

**这不是理论上的漂亮话**：实践中 n 常取 3 到 10，因为太小的 n 收敛慢、太大的 n 方差高。

### 概念 3：n 步 Sarsa 与离轨（难度：高难）
n 步 Sarsa 用 n 步回报更新 `Q(S_t,A_t)`，目标里含 `Q(S_{t+n},A_{t+n})`。**离轨的 n 步方法**要用重要性采样把行为策略的比率乘进每一步，比率数量随 n 增长，方差问题更严重。

### 概念 4：树回溯（难度：高难）
树回溯（Tree Backup）不采样中间动作，而是对每一层的所有可能动作按策略概率加权求和。它结合了“期望更新”的无偏性和“n 步”的在线性，方差比重要性采样版本小很多。

**实例**：三步树回溯，目标 = R1 + γΣ_a π(a|S1)Q(S1,a) 展开到第三层。它把分支全部展开，所以不需要重要性采样比率。

## 常见误解
- 别以为 n 越大越准——实际上 n 大时方差上升，实际性能未必更好。
- 别以为 n 步只能用于预测——实际上它同样可以直接用于控制（n 步 Sarsa）。
- 别以为树回溯只是 n 步的变体——实际上它改变了“中间动作是否采样”这个根本设定。

## 自测题（答案）
1. n=1 的 n 步回报等价于？（答案：A；解析：只剩一个真实奖励加 γV(S')。）
   - A. TD(0)　B. MC　C. 动态规划　D. 树回溯
2. n 增大时方差与偏差如何变化？（答案：C；解析：更依赖真实奖励，偏差减、方差增。）
   - A. 都减　B. 都增　C. 偏差减方差增　D. 不变
3. 树回溯不需要重要性采样的原因是？（答案：B；解析：对中间动作按策略概率加权展开，不采样。）
   - A. 它不需要模型　B. 中间动作全部展开加权　C. 它只用 TD　D. 它只用于同轨

## 复习锚点
- n 步回报 = n 个真实奖励 + 一个估计收尾。
- n 是偏差—方差旋钮：1 是 TD，∞ 是 MC。
- 树回溯展开分支，避免重要性采样的方差爆炸。
