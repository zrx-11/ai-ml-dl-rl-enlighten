# 速查表

## 公式
| 场景 | 内容 |
|---|---|
| 回报 | G_t=R_{t+1}+γR_{t+2}+… |
| 贝尔曼期望 | v_π(s)=Σπ(a|s)Σp[r+γv_π(s')] |
| 贝尔曼最优 | v_*(s)=max_aΣp[r+γv_*(s')] |
| 策略评估 | V(s)←Σπ(a|s)Σp[r+γV(s')] |
| 价值迭代 | V(s)←max_aΣp[r+γV(s')] |
| TD(0) | V(S)←V(S)+α[R+γV(S')-V(S)] |
| Sarsa | Q(S,A)←Q+α[R+γQ(S',A')-Q] |
| Q-learning | Q(S,A)←Q+α[R+γmax_aQ(S',a)-Q] |
| n 步回报 | G=R1+γR2+…+γ^{n-1}Rn+γ^nV(Sn) |
| 半梯度 TD | w←w+αδ∇v(S;w) |
| 策略梯度 | ∇J=E[Σ∇logπ(A|S)q(S,A)] |
| 自注意力无关 | — |

## 算法选择
| 条件 | 选择 |
|---|---|
| 有模型、状态少 | 策略迭代 / 价值迭代 |
| 无模型、分幕 | MC 控制 / TD 控制 |
| 无模型、在线 | Sarsa / Q-learning |
| 状态巨大 | 线性逼近或 DQN |
| 连续动作 | DDPG / PPO 类策略梯度 |

## 排错顺序
回报不升 → 检查奖励尺度与折扣；价值不收敛 → 检查是否踩三要素；训练崩溃 → 检查步长、目标网络、特征归一化；探索不足 → 检查 ε 或内在奖励。
