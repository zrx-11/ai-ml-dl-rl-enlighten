# 模式与框架库

## 框架：假设放松的四级阶梯
这本书的结构就是一条“逐步放松假设”的路：完全模型已知（DP）→ 只能采样（MC）→ 可在线自举（TD）→ 状态太多要逼近（函数逼近）→ 策略直接参数化（策略梯度）。每放松一级，就多一类稳定性问题。

## 决策规则
- 环境可模拟、状态少 → 动态规划或 Dyna。
- 只能采样、有终止 → MC 或 TD，优先 TD。
- 高风险场景 → Sarsa 类同轨方法更保守。
- 状态连续或巨大 → 函数逼近，线性优先，神经网络配目标网络。
- 动作连续 → 策略梯度或 actor-critic。
- 稀疏奖励 → 先设计内在奖励或课程，不要硬训。

## 反模式
- **同时踩三要素还不做稳定化**：函数逼近 + 自举 + 离轨，必然发散。
- **用 MC 处理无终止任务**：回报不收敛，算法没有定义。
- **把奖励设计当小事**：奖励写错会学出荒诞行为。
- **只看平均回报不看方差**：高风险策略在仿真里好，在真实环境里崩。
